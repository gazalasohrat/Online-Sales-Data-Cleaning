# Online Sales Data Cleaning

## Project Overview
This project focuses on cleaning and preprocessing an online sales dataset using Python and Pandas.

## Data Cleaning Performed
- Handled missing values
- Removed invalid negative values
- Converted Order_Date to datetime format
- Checked duplicate records
- Identified outliers using IQR method
- Verified data types and data quality

## Final Dataset
- Rows: 999
- Columns: 14
- Missing Values: 0
- Duplicate Rows: 0

## Tools Used
- Python
- Pandas
- NumPy
- Jupyter Notebook
